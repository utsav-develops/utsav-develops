### A few things I've built

**Sockridge**: an AI agent registry platform, built from scratch.
Go/ConnectRPC backend, ScyllaDB + Redis + PostgreSQL with pgvector, published SDKs for Python/TS/Go.

**WhatsForm**: a WordPress plugin that sends WhatsApp notifications from form submissions.
Full licensing and auto-update server, built and maintained solo.

**Clifr**: AI-powered terminal error summarizer.
A small JS script that hooks into the Claude/Groq APIs and turns cryptic terminal errors into actual fixes.

**Mednic**: clinic management and appointment system.
Built to learn how healthcare data moves and where the friction points are between system-level processes.

**5th Member**: local RAG AI chat engine.

**RepoTales**: turns GitHub repos into comic-strip explainers, powered by the Claude API.
Single-file tool, no backend, no build step.

**Open-source**: contributions to JupyterLab and Atlassian's atlascode VS Code extension.
